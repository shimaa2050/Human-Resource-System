# 💼 Human Resource System


## 🎥 Video Demo: https://youtu.be/AUfI-ba7apk


## Description:


### 💡 Motive:
 I created this project to turn my ideas into real-world solutions and provide Admins, Human Resource workers, and applicants with a web-based job-hunting portal.



### ✅ Reasons why I build this project:

Built a user-centric web platform engineered to simplify the job-hunting process through an intuitive, modern UI and low-friction application workflows.





### 🎯 What did I learn through building this project:

1. Database Design & Modeling: Designed and implemented a custom relational database tailored for candidate data in SQL Server Management Studio (SSMS), selecting optimal data types and establishing data integrity constraints.

2. Branding & Visual Design: Created a modern, appealing platform logo that aligns with the portal’s brand identity and enhances the overall user experience.

3. Full-Stack Data Integration: Connected the web user interface to the SQL Server database using the ASP.NET framework to enable seamless data persistence and retrieval.

4. UI/UX Control Implementation: Built interactive web forms utilizing various ASP.NET controls (e.g., dynamic drop-down lists, buttons, validation controls) to ensure clean data input and fluid navigation.


### 🚀 My project Features:

1. CV Management: Enabled candidates to upload, view, and update/replace their resume at any time.

2. Application Tracking: Provided applicants with real-time status tracking for all submitted job applications.

3. Vacancy Management: Allowed HR staff to create and delete open job listings.
